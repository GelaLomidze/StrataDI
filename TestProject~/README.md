# StrataDI CI Test Project

This minimal Unity project exists only to validate the StrataDI package in CI and locally.

- Unity version: 6000.3.7f1
- StrataDI is referenced from the repository root through `file:../..`
- `com.gelalomidze.stratadi` is listed under `testables` so package tests can be discovered.

Do not add gameplay content to this project.

Generated Unity folders such as `Library`, `Temp`, `Logs`, `Obj`, and `UserSettings`
should remain untracked by Git.
